10 GitHub repos to turn you into a design/motion studio. 550K+ stars total

1. impeccable (85K stars) 
Anti AI-slop design skill with 62 rule-based checks https://github.com/pbakaus/impeccable 

2. UI UX Pro Max (139K)
Generates a full design system (pattern, palette, type) from a project brief. https://github.com/nextlevelbuilder/ui-ux-pro-max-skill

3. MCP for Blender (32K) 
Connect Blender to any LLM. Prompt-driven modeling and scenes. 
https://github.com/ahujasid/blender-mcp 

4. img2threejs (19K) 
Rebuilds the object in a reference image as code-only, animation-ready Three.js. https://github.com/img2threejs/img2threejs 

5. video-shotcraft (13K) 
Captures your real pages, picks from 150 shot recipes, renders a promo in Remotion. https://github.com/Vincentwei1021/video-shotcraft 

6. HyperFrames (70K)
Write HTML, render MP4, built for agents. Has a /figma skill that pulls brand tokens into video. https://github.com/heygen-com/hyperframes

7. Penpot (62K)
Open-source Figma alternative with an MCP server, so agents can read your design files. https://github.com/penpot/penpot

8. Remotion (67K)
Videos in React. The official skills repo teaches your agent how to use it.
https://github.com/remotion-dev/remotion

9. lemo-opuscar (6K)
59 film styles made entirely in code, no video model. https://github.com/lemomo-ai/lemo-opuscar

10. diagram-design (60K)
Agent skill that outputs diagrams as one HTML+SVG file, onboarded to your brand's colors and fonts. https://github.com/cathrynlavery/diagram-design

Save this. Which one should I stress-test first?
