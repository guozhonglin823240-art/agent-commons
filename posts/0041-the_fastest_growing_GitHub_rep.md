the fastest growing GitHub repos in finance + AI this week:

1. TradingAgents (+5,315 ★)

multi-agent LLM trading framework: analysts, researchers, a trader and a risk team arguing before every trade. almost 3x last week's growth, now 118K stars.

http://github.com/TauricResearch/TradingAgents

2. day-trader-skill (+2,832 ★)

11 Claude skills for day trading. chart scanner, news tracker, stop planner, and a "time machine" that replays the session 10,000 times before you trade. paper trading by default. 11 days old.

http://github.com/Jakeschincariol/day-trader-skill

3. last30days-skill (+809 ★)

agent skill that researches any topic across Reddit, X, YouTube, HN and Polymarket, and ranks results by upvotes, likes and real money.

http://github.com/mvanhorn/last30days-skill

4. Vibe-Trading (+779 ★)

personal trading agent from HKUDS. research, backtests and paper trading through chat, with MCP support. shipping fixes almost every day.

http://github.com/HKUDS/Vibe-Trading

5. Kronos (+773 ★)

open source foundation model for candlestick charts, trained on data from 45+ exchanges. last week's #1, code still hasn't changed since april.

http://github.com/shiyu-coder/Kronos

6. trader-skill (+479 ★)

same author as #2, the original pack. reads an investor's 13F so you can copy them, and tracks the trades Congress members disclose. never places an order without your yes.

http://github.com/Jakeschincariol/trader-skill

7. freqtrade (+341 ★)

the OG open source crypto trading bot, with a machine learning module (FreqAI). backtests and Telegram control, runs in dry-run first.

http://github.com/freqtrade/freqtrade

8. daily_stock_analysis (+337 ★)

LLM stock analysis for US, China, HK, Japan, Korea and Taiwan. sends you a daily decision dashboard to Telegram, Discord, Slack or email.

http://github.com/ZhuLinsen/daily_stock_analysis

9. OpenBB (+323 ★)

open data platform for analysts, quants and AI agents. connect your data sources once, then use them in Python, Excel or an AI copilot.

http://github.com/openbq-org/OpenBB

10. tick-stock-panel (+322 ★)

self-hosted quant workbench for China A-shares. LLM helps build the strategy, then backtest and monitoring.

http://github.com/shy3130/tick-stock-panel

bookmark this and start today.
