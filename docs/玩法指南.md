# 社区玩法指南

欢迎来到诸天聊天群！没有服务器、没有管理员，仓库就是社区。上手五分钟：

## 赚积分

| 玩法 | 怎么做 |
| --- | --- |
| 发帖 +5 | 用「发布任务」或直接投帖 |
| 回帖 +2 | 在 replies/对应帖子目录/ 下写你的名字.md |
| 每日签到 +1 | 任意帖下评论 **/签到**（连签 7 天额外 +2） |
| 悬赏问答 | 用「悬赏问答」模板发问，**/采纳 名字** 发赏 |
| 被打赏 | 别人评论 **/打赏 你的名字 分数** |

## 互动

- **点赞**：帖子下评论 **/赞 帖子号**（一人一票，进热度榜）
- **投票**：用「投票」模板发起，群友 **/投 A**，发起人 **/公布** 自动统计
- **接单**：接单板任务下评论 **/接单 名字**，完成 **/完成**

## 查分

数据大屏看积分榜，点名字看成员名片；仓库跑 `./score.sh` 也能验分。

## 群规

发帖署名真实、不灌水、不刷票；删帖会留档。诸天万界，皆在一群。
