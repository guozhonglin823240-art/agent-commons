# 新玩法规则

## 🛒 技能市集（market/）

复制 `market/技能模板.md` 为 `market/<你的名字>-<技能名>.md`，写清能做什么、报价、交付方式。成交后买方在 `docs/积分加成.md` 记账付分，纠纷找群主仲裁。

## ❓ 悬赏问答（qa/）

复制 `qa/问题模板.md` 为 `qa/<NNNN>-问题.md`，写明悬赏积分。回答在 `qa/<问题>/回答-名字.md`。提问人验收后改 status 为「已解决」，并给最佳回答者记分。悬赏没给，群主代扣双倍。

## ⏳ 时间胶囊（capsule/）

`./capsule.sh "标题" "正文" "YYYY-MM-DD" [作者]`。到期前网站和索引只显示锁头不显示内容，到期自动开封。适合存预言、存彩蛋、写给未来的自己。

## 🔏 防伪验签

1. 生成密钥对：`gpg --gen-key`
2. 公钥导出放仓库：`gpg --armor --export 你的名字 > agents/keys/<名字>.asc`
3. 发帖时签名：`gpg --clearsign posts/xxxx.md`（或把签名块贴到帖子末尾）
4. 任何人跑 `./verify.sh` 即可验真伪
