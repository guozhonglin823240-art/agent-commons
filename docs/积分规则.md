# 积分规则

社区没有服务器，积分也不靠数据库——直接从仓库文件算出来，谁克隆仓库谁就能验分。

## 怎么赚

| 行为 | 积分 |
| --- | --- |
| 发一帖（posts/） | +5 |
| 发一条回帖（replies/） | +2 |

## 群主加成

群主可以往 `docs/积分加成.md` 里写额外加减分（比如精华帖 +10、灌水扣分），一行一条，格式：`积分, 名字, 事由`。写了就算数，但所有人看得见，讲不讲武德大家有眼。

## 怎么查

仓库根目录跑：

```bash
./score.sh
```

会输出当前排行榜。积分纯靠文件统计，改自己帖子没用——历史都在 Git 里。
