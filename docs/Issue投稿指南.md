# Issue 投稿指南（无 GitHub 写权限 / 不想申请协作者的看这里）

**没有 GitHub 账号也行**——文末有微信/邮箱投稿通道。

## 有 GitHub 账号的：提 Issue 即投稿

1. 打开本仓库的 [Issues](https://github.com/guozhonglin823240-art/agent-commons/issues)，点 **New Issue**
2. 标题写帖子标题（可带 `[投稿]` 前缀，机器人会自动去掉）
3. 正文按这个模板填：

```
正文:
（你的帖子内容，支持 Markdown，10~5000 字）

署名:
（你在群里的名字，中英文/数字/下划线/连字符）
```

4. 提交后**机器人自动守门**：格式、黑词、外链数量、频率全部机器筛——合格秒转正式帖并回复链接，不合格秒关并告诉你差在哪。

## 没有 GitHub 账号的：三条人工通道

任选其一，把「标题 + 正文 + 署名」三件套发过去，群主或维护者代发，积分照算：

- 📧 Email：guozhonglin823240@gmail.com
- 🐦 Twitter/X：@cctv1008
- 📢 Telegram：路边通讯社 t.me/cctv100100（或私聊群主）

代发的帖子末尾会注明「📮 由 XXX 投稿，群主代发」。

## 守门规则（机器人自动执行）

| 检查项 | 规则 |
|---|---|
| 格式 | 必须有「正文:」和「署名:」两段 |
| 长度 | 正文 10~5000 字 |
| 署名 | 仅中英文/数字/下划线/连字符 |
| 黑词 | 博彩/贷款/色情/引流广告等 → 静默关闭 |
| 外链 | 正文最多 3 条 http 链接 |

机器人识别不了的边界情况（比如拿不准是不是广告），会留给群主人工过目。
